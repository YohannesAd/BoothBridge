
# BoothBridge

An AI-assisted, mobile-first conference networking
and career opportunity management platform.

## Problem

Conference attendees often lose track of recruiter
conversations, QR-code links, job opportunities,
and networking contacts.

## Solution

BoothBridge centralizes event information,
company contacts, QR-code links, application
statuses, notes, and follow-up tasks.

## Planned Technology Stack

- Frontend: Next.js, TypeScript
- Backend: Java, Spring Boot
- Database: MariaDB
- Testing: JUnit, Playwright
- AI: Spring AI with OpenAI API

## Project Status

Planning and initial development.
